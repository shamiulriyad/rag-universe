# 01 — RAG Fundamentals

> **Status:** Planned (Phase 2) · **Level:** Beginner · **Estimated time:** 4–6 hours

## Overview

This module answers the first questions every learner has. What is Retrieval-Augmented Generation? Why was it invented? How is it different from fine-tuning? What are its parts, and how do they work together?

By the end of this module you will be able to explain RAG to a colleague, draw its architecture from memory, and follow a question through the whole pipeline step by step.

## Why This Module Matters

Every later module goes deep on one component of the RAG pipeline. Without the big picture first, those details are hard to place. This module gives you that big picture.
