# What is RAG?

> **Status:** Planned (Phase 2) · **Level:** Beginner
>
> This page is a placeholder. It lists the planned scope so contributors and learners know what is coming. The lesson content has not been written yet.

## Planned Learning Objectives

After this lesson, you will be able to:

- Define Retrieval-Augmented Generation in one sentence.
- Name the three core stages: retrieve, augment, generate.
- Explain the difference between knowledge stored in model weights (parametric) and knowledge retrieved from an external source (non-parametric).
- Recognize RAG in everyday applications, such as document assistants and support chatbots.

## Planned Outline

1. A motivating example: asking an LLM about a document it has never seen.
2. The idea in one sentence.
3. Retrieve → Augment → Generate, illustrated with a simple diagram.
4. Parametric vs non-parametric knowledge.
5. Where the term comes from (Lewis et al., 2020), and how its common usage has broadened since.
6. A toy example that can be followed by hand.
7. Summary and exercises.

## Planned References
