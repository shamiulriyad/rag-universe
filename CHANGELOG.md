## [0.1.0] - 2026-11-12

Phase 1: initial foundation.

### Added

- Repository structure with 14 learning modules and supporting sections.
- Root `README.md` with learning roadmap, topic navigation, and progress table.
- `ROADMAP.md` with lesson-level plans for Phases 1–7 and a topic-ownership table.
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md` (Contributor Covenant 2.1), and this changelog.
- Learner docs: learning path, prerequisites, how to use this repository, and a starter glossary.
- Content templates for topics, paper reviews, and experiments.
- GitHub issue forms (content error, topic request, broken link), pull request template, and a docs-check workflow.
- `scripts/check_links.py` for verifying internal Markdown links and anchors.
- Verified starter reading list of RAG and information-retrieval papers.
- Stub pages for the five Phase 2 fundamentals lessons, clearly marked as Planned.
