# Diagrams

> **Status:** Conventions defined. Shared diagram sources will be added in Phase 2 onward.

RAG-Universe relies on diagrams to explain architecture, data flow, and geometry. This page defines how diagrams are made, stored, and attributed, so they stay consistent and maintainable over time.

## Principles

1. **Original first.** Create diagrams yourself, preferably in Mermaid.
2. **Explain in text.** Every diagram has a nearby text explanation. A diagram should never be the only place where information appears.
3. **Accurate over pretty.** A diagram must match the text and code it accompanies. Do not include components that are not discussed.
4. **No decorative images.** Do not add images that do not teach something.

## Formats

| Format | Use for | Where it lives |
|---|---|---|
| **Mermaid** (preferred) | Pipelines, architectures, flows, sequences, decision trees | Inline in the lesson's Markdown |
| **SVG** | Vector geometry, embedding-space plots, anything Mermaid cannot express | `diagrams/<module>/<name>.svg`, or `<module>/images/` if used by one lesson only |
| **PNG** | Generated plots (for example from matplotlib), only when SVG is impractical | Same as SVG. Commit the script that generates it. |

## Mermaid Conventions

- Use `flowchart LR` for pipelines (left to right) and `flowchart TD` for hierarchies and roadmaps.
- Label every node with plain words, not variable names.
- Use a cylinder node `[(Vector index)]` for data stores.
- Use `subgraph` to separate offline (indexing) from online (query) stages.
- Keep diagrams small. Split anything with more than about 12 nodes.

Example:

```mermaid
flowchart LR
    Q[Question] --> E[Embed]
    E --> S[Similarity search]
    S --> K[Top-k chunks]
    K --> P[Prompt]
    P --> L[LLM]
```

## External Images

External images are allowed only when all of the following are true:

- The source is stable, such as an original paper or official documentation.
- The license permits reuse.
- Attribution is shown directly below the image: *Source: Author, Title, Year, link, license.*

## File Naming

- Lowercase and hyphenated: `rag-architecture.svg`, `cosine-similarity-2d.svg`.
- If a diagram is generated by code, keep the script next to it with the same base name: `cosine-similarity-2d.py`.
